# Development Guidelines

## Technology Stack

- TypeScript
- Remix v3
- Cloudflare Workers
- CSS Modules with custom properties
- pnpm
- Oxlint, Oxfmt, tsgo
- Vitest

## Engineering Principles

- Follow existing repository conventions
- Prefer simple, maintainable code
- Minimize client-side JavaScript
- Use semantic HTML and accessible UI
- Avoid unnecessary dependencies
- Never modify secrets or credentials

## Workflow

1. Inspect relevant files
2. Plan nontrivial changes
3. Implement focused modifications
4. Add appropriate tests
5. Run validation with approval
6. Summarize the changes
